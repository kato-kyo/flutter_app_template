# 開発スケジュール管理表

## 概要

このドキュメントは、基本設計書(30-basic-design.md)の機能一覧に基づいた開発スケジュール管理表です。
各機能をタスクレベルに分解し、進捗管理を行います。

F000 として、プロジェクトのセットアップを行います。

F001以降の機能のタスクについて、共通して下記のタスクを行います。
それぞれのタスクは プルリクエストの単位とします。

T01: feature-design-doc (機能仕様書) の作成
T02: ui層の実装
T03: model層の実装
T04: data層の実装
T05: application層の実装 (feature-design-doc にて必要と判断した場合)
T06: 結合テストの作成・実行

T02 から T05 の 実装は、下記のステップで進めます。
それぞれのステップは、コミットの単位とします。

S01: 実装
S02: リファクタリング (lintの修正を含む)
S03: ユニットテストの作成・実行
