# Flutter DDD開発 `shared`ディレクトリ構成

`shared`ディレクトリは、アプリケーション全体で共通して使用される基盤的なコンポーネントを格納する場所です。
このディレクトリは、アプリケーションの最も基本的な部分を構成し、他のモジュールから依存される要素を含みます。

`lib/src/shared/`に配置します。

## 構造

```
core/
├── shared/
│   ├── state/
│   │   ├── error_view.dart
│   │   └── ...
│   └── widget/
│       ├── loading_indicator.dart
│       ├── error_view.dart
│       └── ...
```

## 各サブディレクトリの役割

### 1. 共有状態（Shared State）

`shared/state`ディレクトリは、複数の機能やUIコンポーネント間で共有される状態管理クラスを含みます。

- **global_state.dart**: アプリケーション全体の状態
- **theme_state.dart**: テーマ設定に関する状態
- **network_state.dart**: ネットワーク接続状態
- **auth_state.dart**: 認証状態（複数の機能で必要な場合）

これらの状態クラスは、特定の機能に属さず、アプリケーション全体で使用されるものです。

### 2. 共有ウィジェット（Shared Widgets）

`shared/widget`ディレクトリは、アプリケーション全体で再利用可能なUIコンポーネントを含みます。

- **loading_indicator.dart**: ローディング表示
- **error_view.dart**: エラー表示
- **empty_state.dart**: データがない状態の表示
- **app_bar.dart**: カスタムアプリバー
- **buttons.dart**: 共通ボタンスタイル
- **text_fields.dart**: 共通テキストフィールド

これらのウィジェットは、一貫したUIを提供し、コードの重複を避けるために使用されます。

### 3. その他の共有要素

以下のような要素も`shared`ディレクトリに含めることがあります：

- **validators**: 共通の入力検証ロジック
- **formatters**: 日付、数値などのフォーマッター
- **extensions**: Dart/Flutterの拡張メソッド
- **hooks**: Flutter Hooksの共有実装
- **mixins**: 複数のクラスで使用されるmixin

## shared ディレクトリと core ディレクトリの違い

- **shared**: 具体的な再利用可能なコンポーネント（ウィジェット、状態など）
- **core**: アプリケーションの基盤となる要素（定数、例外、ルーター、テーマ）

## ベストプラクティス

1. **責任の明確化**: `shared`に配置するコンポーネントは、特定の機能に依存せず、複数の場所で使用されるものに限定する
2. **抽象化**: 再利用可能なようにコンポーネントを適切に抽象化する
3. **テスト**: 共有コンポーネントは特に入念にテストする
4. **ドキュメント**: 他の開発者が使用しやすいように適切にドキュメント化する
5. **適切な粒度**: 必要以上に細かく分けず、関連する機能をまとめる

## まとめ

`shared`ディレクトリは、DDDアプローチを取るFlutterアプリケーションにおいて、コードの再利用性と保守性を高めるための重要な役割を果たします。
適切に設計された共有コンポーネントは、開発効率を向上させ、一貫性のあるユーザー体験を提供するのに役立ちます。
