# プロジェクト概要: Routine Manager

## 1. プロジェクトの目的

日々の繰り返しタスクと週ごとのタスクを効率的に管理し、ユーザーの習慣化と目標達成を支援するシンプルなモバイルアプリケーションを開発する。

## 2. 主要な要件

- **タスク管理:** 日次・週次タスクの登録、編集、削除、一覧表示（リスト形式）、完了管理。
- **カテゴリ管理:** タスクを分類するためのカテゴリ作成、編集、削除。
- **通知機能:** 設定時刻に当日タスクのリマインダーをローカル通知。
- **アチーブメント/バッジ:** 特定条件達成によるバッジ獲得と一覧表示。
- **ローカルデータ保存:** データは端末内に保存（MVPでは認証・同期なし）。

## 3. 主要な目標

- シンプルで直感的なUI/UXを提供する。
- MVPを迅速にリリースし、ユーザーフィードバックを得る。
- 将来的な機能拡張（認証、同期、カレンダー表示等）の基盤を構築する。

## 4. 技術スタック概要

- **フロントエンド:** Flutter
- **状態管理:** Riverpod
- **ローカルDB:** Hive
- **ローカル通知:** flutter_local_notifications

## 5. ターゲットユーザー

日々のタスクや習慣を効率的に管理したいと考えている社会人や学生。
