# MVP要件定義書

## 概要

MVPとは「Minimum Viable Product（実用最小限の製品）」の略で、最小限の機能で市場に投入できる製品バージョンを指します。 このドキュメントでは、初期リリースに含める最小限の機能セットを定義します。

## MVPの目的

- **検証したい主要な仮説/アイデア:** シンプルな日次・週次タスク管理機能がユーザーのルーティン継続に役立つか。
- **収集したいユーザーフィードバック:** アプリの使いやすさ、タスク登録・管理機能の過不足、通知機能の有効性に関するフィードバック。
- **達成したいビジネス目標:** アプリの基本的な利用状況を把握し、今後の機能改善の方向性を定める。

## 主要ユーザーストーリー

MVPで対応する主要なユーザーストーリーを優先度順にリストアップします。

### 最優先（Must Have）

1. **毎日のタスク管理**
    - **As a** ユーザー
    - **I want to** 毎日繰り返すタスク（例: 朝の散歩）を登録できる
    - **So that** 毎日のルーティンを忘れずに管理できる
    - **受け入れ基準:**
        - タスク名、カテゴリ（任意）、通知設定（任意）を入力し、「毎日」を選択して保存できる。
        - 登録したタスクがタスク一覧画面に表示される。
    - **As a** ユーザー
    - **I want to** 登録した毎日のタスクの内容やカテゴリ、通知設定を編集できる
    - **So that** 変更があった場合にタスク情報を最新に保てる
    - **受け入れ基準:**
        - 編集画面でタスク情報を変更し、保存できる。
        - 変更内容がタスク一覧画面に反映される。
    - **As a** ユーザー
    - **I want to** 不要になった毎日のタスクを削除できる
    - **So that** タスクリストを整理できる
    - **受け入れ基準:**
        - タスクを削除する操作を行うと、確認ダイアログが表示され、承認するとタスクが一覧から削除される。
    - **As a** ユーザー
    - **I want to** 実行した毎日のタスクを「完了」にできる
    - **So that** その日の達成状況を確認できる
    - **受け入れ基準:**
        - タスク一覧でタスクの完了チェックボックスをタップすると、ステータスが完了に変わり、見た目も変化する（例: 取り消し線）。もう一度タップすると未完了に戻る。
2. **週次のタスク管理**
    - **As a** ユーザー
    - **I want to** 週ごとに繰り返すタスク（例: 毎週月曜日のゴミ出し）を曜日指定で登録できる
    - **So that** 週ごとの決まった用事を忘れずに管理できる
    - **受け入れ基準:**
        - タスク名、カテゴリ（任意）、通知設定（任意）を入力し、「週次」と実行する曜日（複数選択可）を選択して保存できる。
        - 登録したタスクが、指定した曜日のタスク一覧画面に表示される。
    - **As a** ユーザー
    - **I want to** 登録した週次のタスクの内容や曜日、カテゴリ、通知設定を編集できる
    - **So that** 変更があった場合にタスク情報を最新に保てる
    - **受け入れ基準:**
        - 編集画面でタスク情報を変更し、保存できる。
        - 変更内容がタスク一覧画面に反映される。
    - **As a** ユーザー
    - **I want to** 不要になった週次のタスクを削除できる
    - **So that** タスクリストを整理できる
    - **受け入れ基準:**
        - タスクを削除する操作を行うと、確認ダイアログが表示され、承認するとタスクが一覧から削除される。
    - **As a** ユーザー
    - **I want to** 実行した週次のタスクを「完了」にできる
    - **So that** その週の達成状況を確認できる
    - **受け入れ基準:**
        - タスク一覧でタスクの完了チェックボックスをタップすると、ステータスが完了に変わり、見た目も変化する。もう一度タップすると未完了に戻る。
3. **タスク一覧表示**
    - **As a** ユーザー
    - **I want to** 今日実行すべきタスクの一覧をリスト形式で見ることができる
    - **So that** その日にやるべきことを把握できる
    - **受け入れ基準:**
        - アプリ起動時またはタスク一覧画面を開いた際に、今日の日付に該当する未完了の毎日タスクと週次タスクがリスト表示される。
        - 完了済みのタスクは別途表示されるか、表示/非表示を切り替えられる（要検討）。
4. **カテゴリ管理**
    - **As a** ユーザー
    - **I want to** タスクを分類するためのカテゴリ（例: 仕事, プライベート）を作成・編集・削除できる
    - **So that** タスクを整理しやすくなる
    - **受け入れ基準:**
        - カテゴリ管理画面で、新しいカテゴリ名を入力して作成できる。
        - 既存のカテゴリ名を編集できる。
        - 既存のカテゴリを削除できる（削除時にそのカテゴリに属するタスクの扱いを確認する必要あり）。
5. **リマインダー機能**
    - **As a** ユーザー
    - **I want to** 毎日指定した時刻にその日のタスクを通知してくれるように設定できる
    - **So that** タスクのやり忘れを防ぐことができる
    - **受け入れ基準:**
        - 設定画面でリマインダー通知を有効にし、通知時刻を設定できる。
        - 設定した時刻になると、その日の未完了タスクの概要（件数など）がプッシュ通知で届く。

### 重要（Should Have）

6. **アチーブメント/バッジシステム**
    - **As a** ユーザー
    - **I want to** 特定の条件を達成するとバッジを獲得できる
    - **So that** タスク達成へのモチベーションが上がり、アプリ利用が楽しくなる
    - **受け入れ基準:**
        - 定義された条件（例: 初めてタスク完了、7日間連続タスク完了、合計10タスク完了など）を満たすと、内部的にアチーブメント達成が記録される。
        - アチーブメント達成時、ユーザーにポップアップ等で通知される（シンプルなもので良い）。
        - 獲得したバッジを確認できる一覧画面がある。
        - バッジのデザイン（シンプルなもので良い）がいくつか用意されている。

## MVP対象外の機能

以下の機能は初期MVPには含めず、将来のイテレーションで対応予定です：

1. **ユーザー認証機能 (F001, F002, F003, F004)**
    - 理由: MVPでは単一端末での利用に限定し、早期リリースを優先するため。
    - 予定: Phase2以降で実装（複数端末対応、データ同期と合わせて検討）。
2. **プロフィール機能 (F005, F006)**
    - 理由: ユーザー認証機能に依存するため。
    - 予定: Phase2以降で実装。
3. **タスク一覧表示（カレンダー）(F030)**
    - 理由: MVPではリスト表示に限定し、コア機能を優先するため。
    - 予定: Phase2以降で実装。
4. **ソーシャルログイン (F004)**
    - 理由: ユーザー認証機能の拡張機能であるため。
    - 予定: Phase2以降で実装。

## MVP技術スタック

### フロントエンド

- Flutter (最新安定版)
- 主要パッケージ:
    - `flutter_local_notifications` (ローカル通知用)
    - `shared_preferences` または `hive` (ローカルデータ保存用、要検討)
    - 状態管理ライブラリ (例: `riverpod`, `provider`, 要検討)
    - (バッジ表示用の画像関連パッケージが必要な場合あり)

### バックエンド (MVPで必要な場合)

- 使用しない (データはローカルに保存)

### データ保存

- ローカルストレージ (例: SharedPreferences, Hive, SQLite - 詳細設計で決定)
