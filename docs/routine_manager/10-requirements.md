# 要件定義書

## 1. はじめに

### 1.1 目的

日々の繰り返しタスクと週ごとのタスクを効率的に管理し、ユーザーの習慣化と目標達成を支援するシンプルなモバイルアプリケーションを提供します。

### 1.2 対象ユーザー

日々のタスクや習慣を効率的に管理したいと考えている社会人や学生。
シンプルで直感的なツールを好み、タスク管理の複雑さに煩わしさを感じているユーザー。

### 1.3 プロジェクトの背景

多忙な現代生活において、計画的なタスク実行や習慣化は重要ですが、多くの人が継続に苦労しています。既存ツールは多機能で複雑なものが多く、管理負担を増やすことがあります。本プロジェクトは「日常のルーティン管理を、誰でも簡単に、楽しく継続できるようにする」ことを目指します。

## 2. 機能要件

### 2.1 コア機能

- **タスク管理:**
    - 日次・週次タスクの登録、編集、削除
    - タスクの一覧表示（リスト形式）
    - タスクの完了・未完了の管理
- **カテゴリ管理:**
    - タスクを分類するカテゴリの作成、編集、削除
- **アチーブメント/バッジ:**
    - 特定条件（例: 連続タスク完了、累積タスク完了数）達成によるバッジ獲得
    - 獲得したバッジの一覧表示

### 2.2 ユーザー管理

- MVPではユーザー認証機能は実装しません。データはローカルに保存されます。

### 2.3 データ管理

- データはユーザーのデバイス内にローカル保存されます (Hiveを使用予定)。
- 主なデータ関係:
    - タスクはカテゴリに属することができる (多対一、またはカテゴリなし)
    - タスクには完了記録が紐づく (タスク対完了記録 = 一対多)
    - (将来的に)ユーザーはアチーブメントを獲得する (ユーザー対アチーブメント獲得記録 = 一対多)

### 2.4 外部連携

- MVPでは外部システムとの連携機能はありません。

### 2.5 通知機能

- ユーザーが設定した時刻に、その日の未完了タスクに関するリマインダーをローカル通知で送信します。

|F002|タスク|タスク編集|既存タスクの内容を編集する|高|○|| 
|F003|タスク|タスク削除|既存タスクを削除する|高|○||

|F005|タスク|タスク完了管理|タスクの完了/未完了状態を切り替える|高|○||

**優先度の定義:**
- 高: 最重要機能、MVPに必須
- 中: 重要だが初期リリースには必須ではない
- 低: 付加価値機能、余裕があれば実装

**MVP対象:**
- ○: 最小実用製品(MVP)に含める機能
- ×: MVPには含めない機能（将来のイテレーションで実装）

## 5. 仮定と依存関係

### 5.1 仮定

- ユーザーはiOSまたはAndroidスマートフォンを所有している。
- ユーザーは基本的なスマートフォンの操作、タスク管理の概念を理解している。
- ローカル通知の許可をユーザーが得ている。

### 5.2 依存関係

- Flutter SDK および Dart SDK
- pub.dev で公開されている各種 Flutter/Dart パッケージ (Riverpod, Hive, flutter_local_notifications, uuid, intl, path_provider など)
- OSのローカル通知機能

## 6. 用語集

- **タスク**: ユーザーが管理する日々の作業や習慣。
- **カテゴリ**: タスクを分類するためのラベル。
- **アチーブメント/バッジ**: 特定の目標達成を称えるための報酬。
- **リマインダー**: タスクの実行を促すための通知。
- **MVP (Minimum Viable Product)**: 最小限の価値を提供できる製品バージョン。
- **ローカル保存**:データをユーザーのデバイス内にのみ保存すること。
